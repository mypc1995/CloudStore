## 二、正文（直接粘贴）

```
【云存储管家 v1.2.0】R2 / OSS / COS 图形化管理工具

作者 mypc1995，首次发布于吾爱破解。

────────────────────────────────

找过很多 R2 的图形化工具，要么收费，要么只能上传——传完就不能改名、不能删除，
当上传器用可以，当管理工具不行。于是干脆自己写了一个。

云存储管家：完全免费、无广告、不联网上报。一个工具同时管
Cloudflare R2、阿里云 OSS、腾讯云 COS，
以及任何兼容 S3 协议的自建存储（MinIO、Ceph、SeaweedFS 等）。

────────────────────────────────

■ 能干什么

【浏览】
· 按目录逐级浏览，1000 条一页
· 点表头排序、页内搜索
· 右侧详情面板显示大小 / 类型 / 最后修改时间 / ETag / 存储类别 / 公开链接
· 一键把当前页导出成 CSV 清单

【上传】
· 多选文件、整个文件夹递归上传，或者直接把文件 / 文件夹拖进窗口
· 超过设定大小自动转分片上传，分片并发推送
· 同名对象可选：覆盖 / 跳过 / 自动改名

【下载】
· 单个另存为，或批量按原目录结构下载
· 大文件自动拆成多个字节范围并发拉取
· 先写临时文件，完整下载后才替换目标，不会留下半截文件

【预览】
· 图片直接看
· 文本自动识别 UTF-8 / GB18030 / GBK / Big5 / Shift-JIS，中文文档不再乱码
· 二进制显示十六进制头部
· 内容与元信息双标签页，多选时左右翻阅

【整理】
· 单个或批量删除；删目录会先展开该前缀下的全部对象再分批处理
· 重命名优先在桶内直接完成（内容与元数据不变），失败自动退回下载 + 上传
· 一键复制对象 Key 或公开链接

────────────────────────────────

■ 大文件这块做得比较重

这是我做它的主要理由：

· 分片数超过上限时自动放大分片尺寸；每片独立重试 3 次；
  任一环节失败会主动中止，不留残片持续占空间和计费
· 并行下载：多条连接同时拉取不同片段，各带 3 次重试，全部成功才落地
· 内存恒定：分片缓冲按并发数复用，几百 GB 的文件也是常量内存占用
· 传输队列独立成面板，每条任务显示进度条 / 实时速度 / 剩余时间，可单独取消或重试
· 并发数、分片阈值、分片大小都能在设置里调；
  几十 GB 的文件可以把分片调到 64~128 MB，进一步减少请求数

────────────────────────────────

■ 安装

安装包 34 MB，中文向导，安装路径可以自己选，装完开始菜单和桌面都有快捷方式，
Windows「应用和功能」里也能正常卸载。不想装的话还有免安装单文件版，双击即用。

配置、密钥和日志都放在安装目录里，整个文件夹拷到别的电脑照样能用。
（如果装到了 Program Files 这种普通用户写不了的位置，程序会自动改存到用户目录，不会写不进去。）

────────────────────────────────

■ 关于隐私

· 密钥默认不落盘，只有你主动勾选「在本机记住密钥」才会保存
· 保存时用 Windows 自带的加密机制（当前用户作用域）加密，明文永远不写进文件
· 除了安装 / 卸载项，程序不写注册表；不联网上报，没有任何遥测
· 单实例运行；窗口大小、分栏位置、面板可见性、最后浏览的目录都会记住

────────────────────────────────

■ 已知限制（先说清楚，免得白忙）

· 预览不支持 HEIC / AVIF 等系统未注册解码器的格式，也不渲染 SVG，
  这类文件会提示改用下载或系统程序打开
· 分页按 1000 条一页读取，搜索只作用于当前页
· 上传进度按已读取字节计算，与服务端最终确认之间会有几秒延迟
· 「获取桶列表」需要账号级权限。密钥只有对象级权限时会返回 403 ——
  不影响任何实际功能，直接在桶名框里手动填就行，程序会明确提示
· 阿里云 OSS 的分片标识（ETag）算法与别家不同，跨云搬运时不能直接比对

────────────────────────────────
```
