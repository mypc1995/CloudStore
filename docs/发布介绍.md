### 云存储管家

**作者：mypc1995　|　首次发布：吾爱破解 52pojie　|　版本：1.2.0**

#### 为什么会有这个工具

想在对象存储上图形化地管理文件，于是在网上找了很久。

能找到的，大致分两类：一类是要收费的；另一类是免费的，但功能残缺——只能上传，不能删除、不能改名，传完就只能干看着。用上传器当网盘使显然不叫管理工具。

于是干脆自己做一个。云存储管家就是这么来的：**完全免费，功能够用，不挑令牌类型，三家云都能用。**

#### 支持哪些存储

- **Cloudflare R2**
- **阿里云 OSS**
- **腾讯云 COS**
- **自建 / 私有 S3 兼容存储**（MinIO、Ceph、SeaweedFS 等）

前三个填几项参数就能用；自建存储只需要一个服务地址和一对密钥。
切换厂商只是设置窗口里的一个下拉框。

#### 它能做什么

**浏览**

- 按目录逐级浏览，1000 条一页
- 点表头排序，页内搜索
- 右侧详情面板显示大小、类型、最后修改时间、ETag、存储类别和公开链接
- 一键把当前页导出成 CSV 清单

**上传**

- 多选文件、整个文件夹递归上传，或者直接把文件 / 文件夹**拖进窗口**
- 超过设定大小自动切换为分片上传，分片并发推送
- 上传前可选择同名对象的处理方式：覆盖、跳过，或自动改名

**下载**

- 单个对象另存为，或批量按原目录结构下载
- 大文件自动拆成多个字节范围并发拉取
- 先写入临时文件，**完整下载后才替换目标，不会留下半截文件**

**预览**

- 图片直接看
- 文本自动识别 UTF-8 / GB18030 / GBK / Big5 / Shift-JIS 编码，中文文档不会再乱码
- 二进制文件显示十六进制头部
- 内容与元信息双标签页，多选时左右翻阅

**整理**

- 单个或批量删除；删目录会先展开该目录下的全部对象再分批处理
- 重命名：优先在桶内直接完成（内容与元数据不变），失败自动退回下载 + 上传
- 一键复制对象 Key 或公开链接

> 前面提到的那些"只能上传"的工具，做不到上面这一列。

#### 大文件这块做了什么

这是做它的主要理由，所以这块下得比较重：

- **分片上传**：单个文件分片数超过上限时自动放大分片尺寸；每片独立重试 3 次；任一环节失败会主动中止，不留残片持续占用空间和计费
- **并行下载**：多条连接同时拉取不同片段，各自带 3 次重试，全部成功后才落地
- **内存恒定**：分片缓冲按并发数复用，**几百 GB 的文件也是常量内存占用**，不会把整个文件读进内存
- **看得见的进度**：传输队列单独成面板，每条任务显示进度条、实时速度与剩余时间，可单独取消或重试
- **参数可调**：并发数、分片阈值、分片大小都在设置里开放。几十 GB 的文件可以把分片调到 64~128 MB，进一步减少请求数

#### 关于隐私

- **密钥默认不落盘**，只有你主动勾选「在本机记住密钥」才会保存
- 保存时用 Windows 自己的加密机制（当前用户作用域）加密，明文永远不写进文件
- 配置和日志就放在**安装目录**里，不写注册表、不联网上报；卸载程序也不会删掉你的配置
- 单实例运行；窗口大小、分栏位置、面板可见性、最后浏览的目录都会记住
- 不联网上报，没有任何遥测

#### 快速上手

1. 运行安装程序，安装路径可以自己选（默认装在当前用户目录，免管理员权限）
2. 在对应云的控制台创建访问密钥，记下密钥对与（阿里云 / 腾讯云的）地域、桶名
3. 启动后点右上角 **设置**，先选「服务商」，再填对应字段；桶名可以手动填写，也可以点「获取桶列表」自动选
4. 点「测试连接」确认连通，就可以开始用了

> 不想装也行：同目录里还有免安装单文件版，双击即用，配置存在它旁边。

**关于令牌类型**：列举桶的功能需要账号级权限。密钥只有对象级权限时会返回 403——**不影响任何实际功能**，直接在桶名框里手动填就行，程序会明确提示，不会卡在那里。

#### 系统要求

- Windows 64 位
- 两种形态任选：
  - **安装版**：约 34 MB，运行安装程序即可，**目标机不需要装任何运行库**
  - **免安装单文件**：约 106 MB，解压即用，同样不需要运行库
- 配置保存在安装目录内，**整个目录拷走就能搬到另一台电脑**

#### 第一次打开要等一下？

这是**正常现象**：程序是自带运行环境的单文件，首次运行需要把运行环境解压到临时目录，窗口出现前会有几秒到几十秒的等待（杀毒软件越严格越慢）。第二次启动会明显变快，因为已经缓存了。

如果双击后**一直**没有任何反应，依次检查：

1. 杀毒软件是否拦截或隔离了程序（国产杀软常直接隔离未签名程序）
2. 下载的文件是否完整（随包附带的 `SHA256.txt` 可核对）
3. 是否弹出了 Windows 的「已保护你的电脑」提示（点「更多信息」→「仍要运行」）

程序里还有一个更快的办法：打开 **关于 → 复制诊断信息**，它会一次性收集系统版本、临时目录权限、首次解压状态和到云端的网络连通性，把这段文字发出来就能定位。

程序本身也做了兜底：启动阶段的任何异常都会弹窗并记进日志，不会再无声无息地退出。

#### 已知限制

- 预览不支持 HEIC / AVIF 等系统未注册解码器的格式，也不渲染 SVG；这类文件会提示改用下载或系统程序打开
- 分页按 1000 条一页读取，搜索只作用于当前页
- 上传进度按已读取字节计算，与服务端最终确认之间会有几秒延迟
- 阿里云 OSS 的分片标识（ETag）算法与别家不同，跨云搬运时不能拿它直接比对
