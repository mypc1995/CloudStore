一、两种用法，选一个
------------------------------------------------------------------------

【推荐】安装版
  * 双击「云存储管家-安装程序.exe」
  * 安装时可以自己选安装路径，默认装在当前用户目录下
    （C:\Users\你的用户名\AppData\Local\Programs\云存储管家），
    免管理员权限，装完在开始菜单和桌面都有快捷方式。
  * 目标电脑不需要安装 .NET，也不需要装任何运行库。
  * 卸载：Windows 设置 → 应用 → 找到「云存储管家」→ 卸载；
    或直接运行安装目录里的 unins000.exe。

【备选】免安装版
  * 把「云存储管家.exe」放到任意目录（建议路径不含特殊字符），双击运行。
  * 同样不需要 .NET，配置就存在这个 exe 旁边。
  * 想换地方，把整个文件夹一起拷走即可。


二、配置和日志存在哪
------------------------------------------------------------------------

  * 安装版：就存在【安装目录】里
        安装目录\settings.json     配置（含加密后的密钥）
        安装目录\logs\             日志
    把整个安装目录拷到别的电脑上，配置一起跟着走。
  * 免安装版：存在 exe 所在目录。
  * 例外：如果安装目录没有写入权限（例如装到了 C:\Program Files 下面，
    而你用的是普通账户），程序会自动把配置改存到
        %APPDATA%\R2Manager\
    实际用哪个目录，打开【关于】窗口就能看到。

  * 卸载程序不会删除你的配置（settings.json 里有已保存的密钥）。
    想彻底清除，卸载后手动删掉安装目录即可。

  * 从旧版本升级过来的话，程序第一次启动会把老配置从
    %APPDATA%\R2Manager 自动复制一份到新目录，密钥不用重新填。
    老目录里那份会原样保留，当作备份。


三、第一次运行可能会「没反应」
------------------------------------------------------------------------

这是正常现象，不一定是坏了。

免安装单文件在首次运行时，需要先把运行环境解压到临时目录
（大约 266 MB、170 个文件），这段时间窗口还没出现，看起来像双击了没动静。

  * 普通机器：约 3~5 秒
  * 装有杀毒软件的机器：可能几十秒（杀软要逐个扫描解压出来的文件）
  * 第二次启动会明显变快，因为已经解压缓存过了

如果等了很久仍然一点反应都没有，按下面顺序排查：

  1）杀毒软件拦截
     国产杀软（360、火绒等）经常直接隔离未签名程序。
     → 在杀软的「隔离区 / 安全区」里找到本程序，选择还原，并加入白名单。

  2）Windows 弹了「Windows 已保护你的电脑」
     → 点「更多信息」→ 「仍要运行」。

  3）文件下载不完整
     → 重新下载，用同目录下的 SHA256.txt 核对哈希值。

  4）临时目录不可写
     程序要把运行环境解压到 %TEMP%。如果临时目录被组策略限制或磁盘已满，
     就会失败。可以试试清理磁盘或设置 TEMP 环境变量后重试。

  5）还是搞不定
     打开程序里【关于 → 复制诊断信息】，把内容发给作者。
     里面包含系统版本、临时目录权限、解压缓存状态、配置目录、
     以及到云端的网络连通性，一发过来基本就能定位。


四、连上你的云
------------------------------------------------------------------------

启动后点右上角【设置】，先选「服务商」，然后按对应厂商填：

  Cloudflare R2
    - 账户 ID（Account ID）：控制台 R2 页面上的 32 位十六进制
    - Access Key ID / Secret Access Key：R2 → Manage R2 API Tokens 里创建
    - 桶名：直接手填，或点【获取桶列表】自动选

  阿里云 OSS
    - 地域（Region）：如 cn-hangzhou、cn-shanghai
      * OSS 不支持跨地域访问，端点和地域填错会直接报「桶不存在」
    - AccessKey ID / AccessKey Secret：RAM 访问控制 → AccessKey 里创建
    - 桶名：小写字母 / 数字 / 短横线，3~63 字符

  腾讯云 COS
    - 地域（Region）：如 ap-guangzhou、ap-shanghai
    - SecretId / SecretKey：访问管理 → API 密钥管理
    - 桶名：必须带 APPID 后缀，例如 mybucket-1250000000

  自建 / 私有 S3 兼容存储（MinIO、Ceph、SeaweedFS 等）
    - Endpoint（必填）：服务地址，例如 https://minio.example.com
      或 http://192.168.1.10:9000（没配 TLS 的自建服务用 http 开头）
    - Access Key / Secret Key：自建服务端创建的凭据
    - 地域：大多数自建服务不校验，留空即可
    - 寻址方式：MinIO 选「路径式」；不确定就先用路径式，
      报 404 再换成「虚拟主机式」
    - 桶名：填自建那边的桶名

填完点【测试连接】，通了就点【保存】。

提示：
  * 【获取桶列表】需要账号级权限。密钥只有对象级权限时会提示 403，
    这不影响任何功能 —— 直接在桶名框里手动输入桶名即可。
  * 地域栏很宽容：填 cn-hangzhou、oss-cn-hangzhou，甚至直接粘控制台上的
    完整域名，程序都会自己认出来。


五、密钥安全
------------------------------------------------------------------------

  * 「在本机记住密钥」不勾选时，密钥只在内存里，程序关闭即消失。
  * 勾选后，密钥会用 Windows 自带的加密机制（当前用户作用域）加密后落盘，
    明文永远不写进文件。换台电脑 / 换个 Windows 账号就读不出来。
  * 日志里也不会出现密钥。


六、常用操作
------------------------------------------------------------------------

  * 拖拽上传：把文件或整个文件夹直接拖进主窗口
  * 预览：选中对象按 Enter，或点【预览】
  * 下载：选中后点【下载到本地】
  * 改名：选中后点【重命名】
  * 删除：选中后按 Delete
  * 大文件自动分片上传 + 并行下载，进度、速度、剩余时间都在下方传输队列里
  * 快捷键：Ctrl+U 上传 / Ctrl+F 搜索 / F5 刷新 / Ctrl+L 复制链接 /
           Esc 清空搜索 / ←→ 预览时翻页


七、遇到问题
------------------------------------------------------------------------

日志与配置的位置，打开【关于】窗口就能看到确切路径；
诊断信息里也会一并列出。

程序里的【关于 → 复制诊断信息】会一次性收集排查所需的信息，
反馈问题时请一并附上。
